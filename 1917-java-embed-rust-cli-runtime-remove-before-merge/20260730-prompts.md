   GitHub may change punctuation, wording, capitalization, or the file limit.

   ```text
   wasn't able to review
   maximum number of files
   ```

   Do not depend on `(300)` alone.

2. **False positives from quoted text**
   A human comment or PR description could quote the error.

   Mitigation: inspect only reviews/comments authored by the recognized Copilot reviewer account.

3. **Stale review outcomes**
   An earlier failed review may remain after the PR is reduced and successfully reviewed again.

   Mitigation: evaluate review rounds chronologically and require the latest requested review to have a later successful result.

4. **Race conditions**
   The skill might see the failure response before a later response appears.

   Mitigation: treat the failure as terminal for that review request. Require an explicit remediation and new review request before proceeding.

5. **Undefined automatic remediation**
   Reducing a 300-file PR automatically could destroy intentional work or produce arbitrary splits.

   Mitigation: do not modify or split the PR automatically. Stop for manual intervention.

6. **Other unreviewable outcomes remain**
   Fixing only this message still permits merging after rate limits, unsupported file types, service errors, or other refusal messages.

   - Successful review

   - Timeout/no response

   SKILL.md is procedural guidance, not deterministic code. Vague prose may still be skipped.
